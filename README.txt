Sweet Study Castle — Webアプリ試作品

使い方
1. ZIPを解凍し、index.htmlをブラウザで開きます。
2. iPhoneで使う場合は、index.htmlをWeb公開できる場所（GitHub Pages等）に置いて開くと使いやすいです。
3. 入力内容は開いているブラウザの localStorage に保存されます。ブラウザのデータ削除や別端末では消えることがあるため、「わたし」画面の「データを書き出す」でバックアップしてください。

画面
・おうち：ひとこと、今日の予定
・べんきょう：ToDo、25分タイマー、試験登録
・ノート：日付ごとの予定、元気度、ドキドキ度、日記、メモ
・わたし：詳細プロフィール帳、複数冊保存、目標、お金のメモ、バックアップ

デザインは淡いピンク基調、背景のドット、オリジナルのSVGイラスト（お城・うさぎ・花・本・カレンダー）を使っています。絵文字アイコンは使用していません。
これは試作品で、ユーザーアカウントやクラウド同期はありません。
