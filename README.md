# Sweet Study Castle — MVP

ピンクの甘ロリ風・iPhone向け勉強管理Webアプリです。外部ライブラリ不要のHTML/CSS/JavaScript構成です。

## ファイル
- `index.html`：アプリ本体（画面、機能、localStorage保存）
- `manifest.json`：PWA名・色・起動方法
- `sw.js`：静的ファイルのキャッシュ（HTTPS等の環境で動作）
- `icon.svg`：ホーム画面用アイコン

## ローカルで確認
`index.html` をブラウザで開いて操作できます。Service Workerは通常、HTTPSまたはlocalhostでのみ有効です。iPhoneで本格的に使うにはHTTPSで公開してください。

## 無料公開の例：GitHub Pages
1. GitHubにサインインし、新しいリポジトリを作成（公開設定）。
2. このフォルダ内の4ファイルをリポジトリ直下にアップロード。
3. Settings → Pages → Build and deploymentで、Deploy from a branchを選び、`main` / `/(root)` を指定して保存。
4. 公開URLが発行されたら、iPhoneのSafariで開く。
5. Safariの共有ボタン →「ホーム画面に追加」→ 追加。

公開先の画面やGitHubの仕様は変わる場合があります。公開URLがHTTPSであることを確認してください。

## データ保存・バックアップ
データは同じブラウザの`localStorage`に保存されます。ブラウザのデータ消去、プライベートブラウズ、端末故障で失われる可能性があります。「設定・バックアップ」からJSONを定期的に書き出してください。復元は現在のデータを置き換えます。複数端末同期はありません。

## CSV単語インポート
UTF-8 CSV、列順 `番号,英単語,日本語の意味`。ヘッダー行は任意。例：
```csv
番号,英単語,日本語の意味
1,example,例
2,study,勉強する
```
既存番号は上書きせずスキップします。教材の単語リストをアプリ側に同梱していません。利用者自身が使用権限を確認したデータを登録してください。

## 実装済み
- 今日の勉強時間、目標進捗、ToDo概要、英単語進捗、次の試験カウントダウン
- ToDoの追加・編集・削除、完了状態、教科、優先度、期限
- 15/25/50分タイマー、開始・一時停止・再開・リセット、実経過時間の記録
- 日別・週別・教科別集計と簡易棒グラフ
- 月間シフトカレンダー、勤務時刻、編集・削除
- 英単語番号1〜1900の管理、3段階状態、間違い回数、復習日、学習モード、CSV取込
- 試験・模試記録（合計点、満点、偏差値、判定、メモ）
- ポイント、JSONバックアップ/復元、全削除確認
- PWA manifestとService Worker

## 未実装・制限
- 休憩を自動切替する完全なポモドーロサイクル
- 模試の教科別得点を構造化した入力欄と比較グラフ（メモ欄で記録可能）
- 過去の6月・9月模試の全内訳の初期データ化
- 自動の翌日タスク繰越、学校予定管理、シフト提出日の自動通知
- コレクションアイテムの解放・ホーム装飾
- 夜間をまたぐ勤務、祝日/学校予定連携
- オンライン同期、ユーザーアカウント
- 実機のiPhone Safariでの実機テストは、この成果物の生成環境からは実施していません
- オフライン動作は公開後のService Workerキャッシュに依存し、全状況での保証はありません

## 注意
このMVPは公式の琉球大学2027年度入試要項を検証していないため、科目・配点を登録済みの確定情報として扱いません。必ず公式募集要項で確認してください。


## 追加機能
- ホーム画面に短い「今日のひとこと占い」を表示（ラッキーアイテムなし）
- 日記・メモの作成、編集、個別削除（削除前に確認）
- 日記・メモは localStorage に保存され、JSONバックアップ対象です。
