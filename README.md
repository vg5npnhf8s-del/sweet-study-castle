# スタキャソ（新）

ピンク・リボン・お花・ちょうちょをモチーフにした、iPhone対応のWebアプリです。

## GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作成します（例：`stacaso`）。
2. このZIPを展開し、`index.html`、`manifest.json`、`icon.svg`、`sw.js`をリポジトリの一番上にアップロードします。
3. リポジトリの Settings → Pages を開き、Build and deployment の Source を `Deploy from a branch`、Branch を `main` / `/(root)` にして Save。
4. 公開が完了すると `https://ユーザー名.github.io/リポジトリ名/` のようなURLが表示されます。
5. iPhoneのSafariでそのURLを開き、共有ボタン →「ホーム画面に追加」で使えます。

## 主な機能
- 今日の一言、お気に入り登録、前向きな日替わり占い
- カレンダー、日付別予定、日記、日付メモ
- やるべきことリスト
- 勉強時間計画、教科別勉強記録、週ごとの集計
- デイリー／ウィークリーミッション、散歩・ランニング記録
- 時給・締め期間別の給料見込み、実際の振込額との比較
- JSONバックアップと復元

## 保存について
記録は利用しているブラウザのローカルストレージに保存されます。ブラウザのデータ消去や別端末への移行で失われる場合があるため、定期的に「バックアップ」を使ってください。現時点ではアカウント同期機能はありません。
