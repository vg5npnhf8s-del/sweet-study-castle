# Sweet Study Castle — MVP

ピンクの甘ロリ風・iPhone向け勉強管理Webアプリです。外部ライブラリ不要のHTML/CSS/JavaScript構成です。

## ファイル
- `index.html`：アプリ本体（画面、機能、localStorage保存）
- `manifest.json`：PWA名・色・起動方法
- `sw.js`：静的ファイルのキャッシュ（HTTPS等の環境で動作）
- `icon.svg`：ホーム画面用アイコン

## ローカルで確認
`index.html` をブラウザで開いて操作できます。Service Workerは通常、HTTPSまたはlocalhostでのみ有効です。iPhoneで本格的に使うにはHTTPSで公開してください。

## 無料公開の例：GitHub Pages
1. GitHubにサインインし、新しいリポジトリを作成（公開設定）。
2. このフォルダ内の4ファイルをリポジトリ直下にアップロード。
3. Settings → Pages → Build and deploymentで、Deploy from a branchを選び、`main` / `/(root)` を指定して保存。
4. 公開URLが発行されたら、iPhoneのSafariで開く。
5. Safariの共有ボタン →「ホーム画面に追加」→ 追加。

公開先の画面やGitHubの仕様は変わる場合があります。公開URLがHTTPSであることを確認してください。

## 追加機能の使い方
- 「予定」タブで、カレンダーの日付をタップしてシフトまたは通常予定を登録できます。
- 「お金」タブで時給・月の給与目標を設定できます。時給の初期値は1,000円です。勤務時間から休憩分を引いて予想給与を算出します。
- 実際の給与は入金日と金額を別途登録してください。予想給与は税金等を差し引く前の概算です。
- 支出や買い物も記録でき、今月の受取給与・支出・残額を確認できます。
- 勉強で得たポイントを使ってごほうびアイテムを解放できます。

## データ保存・バックアップ
データは同じブラウザの`localStorage`に保存されます。ブラウザのデータ消去、プライベートブラウズ、端末故障で失われる可能性があります。「設定・バックアップ」からJSONを定期的に書き出してください。復元は現在のデータを置き換えます。複数端末同期はありません。

## CSV単語インポート
UTF-8 CSV、列順 `番号,英単語,日本語の意味`。ヘッダー行は任意。例：
```csv
番号,英単語,日本語の意味
1,example,例
2,study,勉強する
```
既存番号は上書きせずスキップします。教材の単語リストをアプリ側に同梱していません。利用者自身が使用権限を確認したデータを登録してください。

## 重要な注意（Full Update）
- 記録は端末内のlocalStorageに保存されます。データ移行前にJSONバックアップを保存してください。
- 生活ログは手入力です。iPhoneのスクリーンタイム／ヘルスケアの自動読取や、通知・複数端末同期は実装していません。
- 植物の成長はアプリ内の演出です。現実の植物管理情報ではありません。
- ほめほめポイントは既存の勉強ポイントとは別です。生活・勉強ポイントは記録状況に応じた目安で、休んだ日にも既存の進行や植物が減ることはありません。
- iPhone実機での動作確認は、この環境では実施していません。公開前にバックアップを取り、GitHub Pages等でテストしてください。
